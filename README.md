### Cryptocurrency Dashboard (Power BI)

An interactive Cryptocurrency Dashboard built in Power BI to analyze and visualize cryptocurrency market data. This project focuses on transforming raw data into meaningful insights through dynamic visuals, KPIs, and user-friendly filtering.

### Key Features

* Interactive dashboard with a clean and modern UI

* KPI cards for Total Coins, Market Cap, Price, and Trading Volume

* Cryptocurrency performance comparison across multiple coins

* Price trend analysis using line and area charts

* Market capitalization distribution with visual breakdowns

* Trading volume analysis for better market insights

* Top-performing and lowest-performing cryptocurrency identification

* Dynamic slicers to filter data by coin and category

* DAX measures for calculated metrics and KPIs

* Data cleaning and transformation using Power Query

* Responsive report layout for easy navigation

* Insightful visualizations to support data-driven analysis

### Tools & Technologies

* Power BI

* Power Query

* DAX (Data Analysis Expressions)

* Excel / CSV Dataset

* Data Visualization & Dashboard Design

### Project Objective

The goal of this project is to demonstrate Power BI skills by creating an interactive dashboard that helps users explore cryptocurrency market data, compare digital assets, and gain valuable analytical insights through effective visual storytelling.
